# Glidechart website

The landing, privacy, support and terms pages of Glidechart, a PT chart and superheat/subcool calculator for
R-410A, R-32, R-454B, R-22 and R-134a, served by GitHub Pages at https://soloinc-projects.github.io/glidechart/.

This repository holds only the site's static files. The app's code is not here.

- `index.html`: the landing page
- `privacy/`: the privacy policy (the stores' privacy policy address)
- `support/`: how to reach support and the first questions people ask (the stores' support address)
- `terms/`: the stores' standard terms, the reference-only notice and the open-source notices
- `assets/site.css`, `fonts/` (SIL OFL 1.1, with their licences), icons and `screenshots/`
